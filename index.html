02

How the engine decides

First it finds where a stop makes sense, from tank size, fuel level, consumption and a safety margin. Then it scores each station in that window by net savings.

net_savings = (avg_price − price) × litres_to_fill
            − (2 × detour_km / 100) × consumption × price

03

From prototype to platform

After the first results, the CEO asked for more: several companies, logins, fleet management and a savings dashboard. The screens below come from the app running on live public data (22/10/2026 prices).

  • Each company only sees its own data. I tested it with two real companies side by side.
  • Rights are re-read from the database on every request, so a disabled account loses access at once.
  • Savings only count when a driver confirms a station. A smaller number, but one a client can trust.

  1. The driver enters a trip

    Start, destination, tank level and the truck. The React screen sends it with the login token.

  2. FastAPI checks who is asking

    It validates the data, reads the role from the database and keeps the request inside the driver's company.

  3. The engine does the maths

    The optimizer finds the stop window and scores every station. It knows nothing about users or HTTP, so it can move into BFRET's main software later.

  4. Live data, zero cost

    Prices from the French government feed, routes from OSRM, places from Nominatim. The search is saved with the offers it showed.

  5. The manager sees real savings

    When the driver picks a station, the saving is read back on the server, never trusted from the browser, and added to the fleet total.

Fuel alert verification assistant

InnoSoft Tracking

A fleet tracking platform raises fuel theft alerts, and many are false: sensor noise, slopes, voltage drops. Today an expert checks every graph by hand before calling the client. My tool prepares each case, suggests a decision with its reasons, and learns from every answer the expert gives.

  • Human in the loop: the system never contacts a client on its own
  • Isolation Forest to start, Random Forest once the expert has labelled alerts
  • Three levels of autonomy, 10 % random audit and an automatic stop if a real theft is missed

Python · pandas · scikit-learn · SQLite · Streamlit

The scores in the demo come from simulated data. Real data from the Wialon API comes next.

Kounach, a shop app for a bookshop

Bookshop and stationery store next to a high school

At back-to-school time the shop serves up to 100 customers an hour, with no system at all. Kounach is a fast checkout, stock, customer credit (the “kounach” notebook) and printing service in one app that keeps working when the internet drops.
